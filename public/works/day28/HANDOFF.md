# 다음 에이전트를 위한 기술 인계

## 수정 기준

`transfer.html`이 유일한 실행 원본입니다. CSS는 `<style>`, 애니메이션은 마지막 `<script>`, 실루엣과 필터는 본문의 `<svg>` 안에 있습니다. 텍스처는 data URI로 내장했습니다. 빌드나 외부 의존성 없이 파일을 직접 수정할 수 있습니다. 별도의 CSS/JS 사본을 두지 않아 버전 불일치를 피했습니다.

## 코드 위치를 찾는 검색어

- `human`, `jointLeg`, `hingedArm`: 사람의 프로필·관절·보행
- `animalLeg`, `ribbon`: 강아지/사슴의 분절된 관절과 실루엣 연결
- `cat`: 네 자세를 보간하는 고양이 달리기
- `deer`, `hound`: 동물 몸통·머리 형태
- `groundY`: 불규칙한 지면 높이. 지면 SVG와 동일한 기준점, 배율 1.24, 접점 여유 +7px
- `castTypes`: 9종의 이름과 크기
- `family`: 비슷한 인물 외형의 중복 차단 규칙
- `procession`, `lastExit`, `lastArrival`: 최대 활성 수 5, 재등장 간격, 최근 사용 우선순위
- `position`, `gait`: 실제 이동 거리와 자세 위상의 관계
- `encounters`: 이동 궤적의 정확한 교차 시각을 사전 계산
- `scene`: 시간에 따른 소유권 교환과 캐릭터/그림자 렌더링
- `shadow-union`: 그림자 부품을 합친 하나의 알파 마스크
- `city-hide-`: 건물의 앞뒤 가림 마스크
- `ink-bank`: 중간 명암을 충분히 포함한 지면 PNG
- `corner-mask`, `corner-blur`, `corner-grain`: 가장자리 효과
- `scattered-stars`: 고정된 비균등 별 배치

## 일정과 그림자

일정은 seed 90317의 의사난수로 생성되어 재생/탐색 시 동일합니다. 단순히 프레임마다 무작위로 뽑지 않습니다. 등장부터 퇴장까지의 전체 이동 구간을 활성으로 계산하므로 부분적으로 걸쳐 보이는 오브젝트도 상한에 포함됩니다.

그림자는 각 교차 이벤트에서 두 캐릭터의 소유권을 교환합니다. 렌더 시 새 소유자의 x 위치, 진행 방향, 보행 위상을 적용하고, 전달된 실루엣의 종류와 원래 크기를 유지합니다. 페이드, X자 보간, 가로 스케일을 0으로 통과시키는 뒤집기 애니메이션은 없습니다. 방향은 교차 순간 바뀝니다.

같은 방향 추월에서도 소유권이 교환됩니다. 서로 다른 속도 때문에 기존 그림자를 다른 상대에게 다시 전달할 수도 있습니다.

- 이 검증은 브라우저 전체 자동화 테스트가 아닙니다. 브라우저별 전체화면, SVG 필터 성능, 탭 비활성화 복귀 등은 배포 전 실제 브라우저에서 확인하십시오.

- 앞뒤 가림과 그림자 렌더는 SVG 마스크를 사용하며, 모서리 블러는 장면 `<use>` 복제입니다. 저사양 기기에서 필터 비용을 확인하십시오.
- 첨부 레퍼런스 이미지는 사용자가 제공한 참고 자료이며 재배포 패키지에는 포함하지 않았습니다. 후속 작업은 REQUIREMENTS.md의 최신 결정과 사용자의 새 지시를 우선하십시오.

## 오디오 인계

`const soundscape`가 Web Audio 구현입니다. `foot`은 종류별 디딤 소리, `wind`/`insects`/`bird`는 환경음입니다. `burst`가 잡음/사인파 음원, 필터, 짧은 음량 곡선, 좌우 위치를 구성합니다. 단일 2초 잡음 버퍼를 재사용하고 종료된 노드는 연결을 해제합니다. 마스터 음량은 0.46이며 컴프레서를 거칩니다.

`update(time)`은 실제 애니메이션 시간으로 보행 위상의 접촉 시점을 검사합니다. 환경음 간격은 AudioContext 시간으로 결정합니다. Sound 토글을 켜거나 M으로 켤 때 `unlock()`을 호출합니다. 기본값은 음소거이며, 일반 화면 클릭은 소리를 켜지 않습니다. `window.artwork.sound`로 음소거 상태 및 제어 함수에 접근할 수 있습니다. 시각 일정 난수와 오디오 난수는 독립적이므로 오디오 활성화가 등장 순서를 바꾸지 않습니다.

검증은 모의 Web Audio 노드로 자동재생 없음·입력 후 시작·유한한 음량 곡선·정지/숨김/음소거 억제를 확인했습니다. 실제 청취를 통한 음질·음량 검증과 브라우저별 테스트는 수행하지 않았습니다. `preview.png` 및 별도 기존 MP4는 오디오를 포함하지 않습니다. 소리는 HTML 상단 Sound Off 버튼을 눌러 확인하십시오.

## 작은 보폭 효과음 완화

강아지·사슴의 디딤 소리 진폭을 약 64~73% 낮추고 필터 주파수와 타격음을 낮춰 빠른 디딤이 과도하게 도드라지지 않도록 조정했습니다. 보행 동기화는 유지합니다. BGM은 최종 요청으로 취소했으며 포함하지 않습니다.

## 최종 보폭·토글 수정

사슴 stride는 23에서 36으로 증가(약 57%). 위·아래 다리 길이는 54/53, 발 들림 높이는 16. gait의 stride도 동일하게 36으로 변경해 물리적 이동 속도를 유지하며 걸음 주기는 느려집니다. HTML 상단 우측 `#sound-toggle`은 상태에 따라 Sound On/Off와 aria-pressed를 갱신합니다. 버튼의 Space/Enter 기본 동작은 전체 재생 단축키와 충돌하지 않습니다.
