# 환승 — 컷아웃 그림자극

1920×1080 기준의 로컬 HTML 아트워크입니다. 화면은 16:9 비율로 창에 맞춰 축소됩니다.

## 실행

`transfer.html`을 브라우저로 열면 됩니다. 설치, 빌드, 서버, 인터넷 연결이 필요 없습니다. CSS, JavaScript, SVG 도형, PNG/JPEG 텍스처가 모두 HTML 한 파일 안에 들어 있습니다. 외부 폰트나 라이브러리는 사용하지 않습니다.

- 상단 Sound Off 버튼: 효과음 시작. Sound On 버튼: 음소거 (기본 Off)
- M: 전체 효과음 음소거 / 해제
- Space: 재생 / 일시정지
- R: 시작 위치(4초)로 되돌리기
- S: 기본 흑백 / 제한된 색채 전환
- F 또는 더블클릭: 전체화면 (브라우저 지원에 따름)
- OS에서 동작 줄이기가 켜져 있으면 정지 상태로 시작합니다. Space로 재생할 수 있습니다.

## 파일

- `transfer.html`: 실행과 수정의 기준이 되는 완전한 단일 파일
- `REQUIREMENTS.md`: 사용자의 누적 요구사항과 최종 우선순위
- `CHANGELOG.md`: 주요 수정 내역
- `HANDOFF.md`: 다음 에이전트가 이어서 작업하기 위한 구조 설명
- `verify.cjs`: Node.js 기본 모듈만 사용하는 일정·중복·그림자 검증
- `preview.png`: 최신 장면의 정적 미리보기

검증 실행: `node verify.cjs`

GitLab에 이어서 작업할 경우 이 폴더를 저장소에 넣고 `transfer.html`을 수정하면 됩니다. 이번 작업에서 GitLab 접근·커밋·업로드는 수행하지 않았습니다. 원본 레퍼런스 이미지나 영화 클립은 실행 파일에 포함되지 않으며, 요구사항 문서에 참고 방향을 기록했습니다.

## 효과음

Web Audio API로 HTML 안에서 직접 합성합니다. 외부 음원·다운로드·네트워크 요청은 없습니다. 사람의 발걸음, 강아지의 가벼운 디딤, 사슴의 짧은 발굽 소리, 고양이의 빠른 착지가 보행 주기에 맞춰 발생합니다. 위치에 따라 좌우 음상이 바뀌며 화면 밖으로 갈수록 작아집니다. 낮은 바람, 짧은 풀벌레, 드문 새소리가 불규칙한 간격으로 더해집니다. 실제 현장 녹음 음원은 아닙니다.

상단 Sound Off 버튼을 누르면 소리가 시작됩니다. M으로 끄거나 켤 수 있습니다. 일시정지와 탭 숨김 상태에서는 음량이 잦아들며 새 효과음은 발생하지 않습니다. 브라우저가 오디오를 지원하지 않아도 시각 애니메이션은 실행됩니다.
